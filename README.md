# Γεννήτρια Διαγωνισμάτων

Εφαρμογή Windows που φτιάχνει διαγωνίσματα μαθηματικών σε Word από φωτογραφίες ή screenshots
θεμάτων. Ο Claude διαβάζει τις εικόνες και το πρόγραμμα βγάζει `.docx`:

- με **επεξεργάσιμες εξισώσεις Word** (ημ, συν, συστήματα, ορίζουσες, κλάσματα…),
- με **σχήματα επανασχεδιασμένα** ως επεξεργάσιμα (δεξί κλικ → «Μετατροπή σε σχήμα»),
- με περιθώρια και στυλ από **δικό της διαγώνισμα-πρότυπο**, και πάντα με «Σελίδα X από Y» στο κέντρο
  της κεφαλίδας, υποσέλιδο «Τάξη … Επιμέλεια: …» και γραμματοσειρά της επιλογής της (προεπιλογή Cambria 12),
- με **μονάδες** που μοιράζονται αυτόματα (σύνολο 100) και αλλάζουν ελεύθερα.

Πριν βγει το Word, η **οθόνη ελέγχου** δείχνει δίπλα δίπλα το πρωτότυπο και τη μεταγραφή με ζωντανή
προεπισκόπηση, ώστε να διορθωθεί ό,τι χρειάζεται. Όσα ο Claude δεν διάβασε με βεβαιότητα
σημειώνονται με κίτρινο.

## Εγκατάσταση (μία φορά)

1. Κατεβάστε το `Diagonismata-Setup-x.y.z.exe` από τα **Releases** (δεξιά στη σελίδα του repository).
2. Τρέξτε το. Αν τα Windows βγάλουν «Τα Windows προστάτευσαν τον υπολογιστή σας», πατήστε
   **Περισσότερες πληροφορίες → Εκτέλεση οπωσδήποτε**. Εμφανίζεται επειδή το πρόγραμμα δεν έχει
   ψηφιακή υπογραφή. Δεν χρειάζονται δικαιώματα διαχειριστή.
3. Ανοίξτε την εφαρμογή → **⚙ Ρυθμίσεις**:
   - **Σύνδεση με συνδρομή Claude** (προεπιλογή): πατήστε «Σύνδεση με συνδρομή…». Ανοίγει ένα
     μαύρο παράθυρο και μετά ο browser για σύνδεση στον λογαριασμό Claude. Στο τέλος εμφανίζεται
     ένα μακρύ token (`sk-ant-oat…`). Αντιγράψτε το, επικολλήστε το στο πεδίο και πατήστε
     «Αποθήκευση». Το token ισχύει περίπου ένα χρόνο.
   - **Πρότυπο:** «Επιλογή διαγωνίσματος ως πρότυπο…» → διαλέξτε ένα δικό σας διαγώνισμα `.docx`.
     Από αυτό κρατιούνται κεφαλίδα, υποσέλιδο, περιθώρια και γραμματοσειρές.
   - **Δοκιμή σύνδεσης** για επιβεβαίωση.

## Χρήση

1. **Διαγώνισμα:** τίτλος, υπότιτλος, ημερομηνία (ή κενή γραμμή), υποσέλιδο, πλήθος θεμάτων.
   Σε κάθε θέμα ρίχνετε εικόνες (σύρσιμο, κλικ ή **Ctrl+V** για screenshot στο επιλεγμένο θέμα).
   - Μία εικόνα ανά θέμα: τα α), β), γ) της άσκησης γίνονται Α1, Α2, Α3.
   - Πολλές εικόνες σε ένα θέμα: κάθε εικόνα γίνεται Γ1, Γ2… και τα α), β) της γίνονται i), ii).
2. **Μεταγραφή θεμάτων →**: οι εικόνες στέλνονται παράλληλα (συνήθως 10–60 δευτ. η καθεμία).
3. **Έλεγχος:** διορθώνετε κείμενο/εξισώσεις (μέσα σε `$…$`), επιλέγετε για κάθε σχήμα
   «επανασχεδιασμένο» ή «πρωτότυπη εικόνα», ρυθμίζετε τις μονάδες.
4. **Δημιουργία Word** → «Άνοιγμα στο Word».

> Ανοίγετε το αρχείο στο **Word**. Η προεπισκόπηση των Windows και το LibreOffice δεν δείχνουν τις
> εξισώσεις του Word, ενώ το αρχείο είναι σωστό.

## Αλλαγές χωρίς νέα έκδοση

| Τι | Πού |
| --- | --- |
| Τρόπος σύνδεσης (συνδρομή ή API) | Ρυθμίσεις → Σύνδεση με τον Claude |
| Μοντέλο | Ρυθμίσεις → Μοντέλο. Τα `opus` / `sonnet` ακολουθούν αυτόματα το νεότερο μοντέλο. Δέχεται και πλήρες όνομα (π.χ. `claude-opus-5-5`). |
| Κανόνες μεταγραφής (οδηγίες προς τον Claude) | Ρυθμίσεις → «Επεξεργασία κανόνων». Ανοίγει το `rules.md` στο Σημειωματάριο και οι αλλαγές ισχύουν από την επόμενη μεταγραφή. |
| Μορφή υπο-ερωτημάτων, στοίχιση «Μονάδες» | Ρυθμίσεις → Word |

Οι ρυθμίσεις βρίσκονται στο `%APPDATA%\Diagonismata\settings.json`. Τα token και κλειδιά
αποθηκεύονται στη Διαχείριση διαπιστευτηρίων των Windows, όχι σε αρχείο.

### Anthropic API αντί για συνδρομή

Ρυθμίσεις → «Anthropic API» → επικόλληση κλειδιού από το <https://console.anthropic.com>
(χρέωση ανά χρήση, ξεχωριστή από τη συνδρομή). Τα σύντομα ονόματα μοντέλων (`opus` κ.λπ.)
μεταφράζονται σε πλήρη ονόματα API από τον πίνακα «Αντιστοίχιση σύντομων ονομάτων».

## Για τον προγραμματιστή

### Δομή

```
app/
  main.py              εκκίνηση (παράθυρο pywebview· --browser για λειτουργία browser· --selftest)
  bridge.py            μέθοδοι που καλεί η οθόνη (JS → Python)
  config.py            ρυθμίσεις, μοντέλα, providers, αποθήκευση μυστικών (keyring)
  providers/           ένας φάκελος ανά τρόπο σύνδεσης
    agent_sdk.py       συνδρομή Claude μέσω Claude Agent SDK
    anthropic_api.py   Anthropic API με κλειδί
  transcribe.py        σχήμα JSON μεταγραφής, προετοιμασία εικόνων, παράλληλη εκτέλεση
  figures.py           spec σχήματος → SVG/PNG (matplotlib) + αριθμητικοί έλεγχοι γεωμετρίας
  docx_build.py        Markdown → pandoc → διορθώσεις (.docx), έλεγχος round-trip εξισώσεων
  points.py            κατανομή μονάδων
  updates.py           έλεγχος/λήψη/εγκατάσταση ενημερώσεων από GitHub Releases
  resources/rules.md   οι κανόνες μεταγραφής (system prompt)
  ui/                  HTML/CSS/JS (KaTeX, marked — τοπικά, χωρίς internet)
build/                 PyInstaller spec, Inno Setup, εικονίδιο
docs/                  οδηγός χρήσης, οδηγίες GitHub
scripts/               στοιχεία build, απόσπασμα CHANGELOG, δοκιμαστικά εργαλεία
CHANGELOG.md           ιστορικό αλλαγών (εμφανίζεται στο «Τι νέο»)
.github/workflows/     αυτόματο build για Windows
tests/                 δοκιμές πυρήνα (χωρίς κλήσεις στον Claude)
```

### Νέος τρόπος σύνδεσης

1. Νέα κλάση στο `app/providers/` που υλοποιεί το `Provider.extract_json()` και το `ping()`.
2. Μια γραμμή στο `PROVIDERS` (`app/config.py`) και ένας κλάδος στο `get_provider()`
   (`app/providers/__init__.py`).

### Τοπική εκτέλεση

```bash
pip install -r requirements.txt       # + pandoc στο PATH
python app/main.py                    # παράθυρο
python app/main.py --browser          # στον browser (http://127.0.0.1:8765)
python app/main.py --selftest         # αυτοέλεγχος χωρίς κλήση στον Claude
python -m pytest -q
```

### Εκδόσεις και ενημερώσεις

- Ο αριθμός έκδοσης είναι στο `app/__init__.py` (`__version__`, μορφή ΜΕΙΖΩΝ.ΕΛΑΣΣΩΝ.ΔΙΟΡΘΩΣΗ).
- Κάθε έκδοση **πρέπει** να έχει ενότητα `## [X.Y.Z] — ημερομηνία` στο `CHANGELOG.md`, αλλιώς το build αποτυγχάνει.
- Όταν στο `main` ανεβαίνει κώδικας με αριθμό έκδοσης που δεν έχει δημοσιευτεί, το build δημιουργεί
  **αυτόματα** GitHub Release `vX.Y.Z` με το πρόγραμμα εγκατάστασης και σημειώσεις από το CHANGELOG.
- Η εφαρμογή ελέγχει κατά την εκκίνηση το `releases/latest` του repository (`app/updates.py`) και,
  αν υπάρχει νεότερη έκδοση, την κατεβάζει και την εγκαθιστά σιωπηλά (Inno Setup `/SILENT`).
- Στο «Σχετικά» φαίνονται έκδοση, αριθμός build, commit και ημερομηνία (`app/resources/build_info.json`,
  γράφεται από το `scripts/make_build_files.py`), και στις Ιδιότητες του `.exe` στα Windows.

### Build (GitHub Actions)

Κάθε `push` στο `main` χτίζει το πρόγραμμα εγκατάστασης σε Windows: δοκιμές → στοιχεία build →
PyInstaller → **αυτοέλεγχος του .exe** → Inno Setup → (αν η έκδοση είναι νέα) Release.
Αναλυτικά βήματα για μη προγραμματιστές: [docs/github-guide.md](docs/github-guide.md).

Για νεότερο Agent SDK/CLI αρκεί ένα νέο build, γιατί το `requirements.txt` ορίζει μόνο ελάχιστη έκδοση.
